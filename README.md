## 1. Start with the operation / 先明确工艺动作

| Product category / 通用品类 | Information to prepare / 需准备的信息 |
| --- | --- |
| Compact sterile tubing connection equipment / 小型无菌接管设备 | Tubing material and dimensions, connection operation, dry or liquid-filled state, sterilization history and operating frequency / 管材与尺寸、连接动作、空管或带液状态、灭菌经历与频次 |
| Handheld TPE tubing sealing equipment / 手持式 TPE 封管设备 | Tubing specification, sealing and disconnection workflow, liquid state and required records / 管路规格、封管断开流程、液体状态与记录需求 |
| Tangential flow filtration (TFF) / 切向流过滤 | Feed characteristics, membrane type, starting/final volumes, concentration or buffer-exchange objective, intended TMP and available measurements / 料液特征、膜型、起始与终体积、浓缩或换液目标、目标 TMP 与可用测量条件 |
| Peristaltic pumping / 蠕动泵 | Fluid, required transfer flow, tubing ID/OD/material, pressure conditions and control method / 介质、输送流量、管路内外径与材质、压力工况和控制方式 |
| Cell thawing equipment / 细胞复苏设备 | Container format, sample volume range, starting condition, handling workflow and desired records / 容器形式、样品体积范围、起始状态、操作流程与记录需求 |
| Isolation systems / 隔离系统 | Process steps, materials entering/leaving, working space, containment or product-protection objective, cleaning/decontamination needs / 操作步骤、物料进出、空间、隔离或产品保护目标、清洁去污需求 |
| Single-use tubing and containers / 一次性管路与容器 | Fluid-contact material, tubing ID/OD, container or connection needs, pressure/temperature and sterilization method / 接液材质、管路内外径、容器或连接需求、压力温度与灭菌方式 |
| Filtration and integrity testing / 过滤与完整性测试 | Filtration objective, fluid and membrane information, test method required by your procedure and acceptance criteria to be reviewed / 过滤目标、介质与滤膜信息、现有规程要求的测试方法和待核对接受标准 |
| Cell culture consumables / 细胞培养耗材 | Culture workflow, reagent or vessel type, intended scale and material/handling requirements / 培养流程、试剂或容器类型、使用规模与材质操作要求 |
| Reactors and process analysis / 反应器与过程分析 | Intended process, working-volume range, measurements, sampling and data-interface requirements / 工艺用途、工作体积范围、测量、取样与数据接口需求 |
| High-pressure homogenization / 高压均质 | Feed description, batch volume, processing objective, temperature constraints and intended operating requirements / 物料概况、批次体积、处理目标、温度限制与预期运行要求 |

These fields help frame a review. They do not establish that any particular configuration meets the requested conditions.

以上字段用于组织选型核对，不能单凭填写内容判定某个配置满足实际工况。

## 2. Tubing connection and sealing are different operations / 接管与封管断开要分开

**Connection** joins applicable tubing segments to create a continuous path. A connection inquiry should identify both tubing segments and the intended connection conditions.

**接管**是连接适配的管路段，形成连续通路。询价时应分别说明两端管路及连接条件。

**Sealing and disconnection** closes applicable tubing before separation. State whether a sealed end, a defined separation step or both are needed. Confirm how separation is performed for the proposed configuration.

**封管与断开**是在分离前形成封管端。请说明需要封闭管端、分离动作还是两者兼有，并核对拟选配置的具体分离方式。

For either operation, review tubing formulation/grade, ID, OD, sterilization history, dry or liquid-filled state and process conditions. A diameter range alone does not confirm compatibility or the performance of the final process.

两类操作均需核对管材配方或等级、内外径、灭菌经历、空管或带液状态及实际工况。管径落入某个范围，仍不足以确认适配性或最终工艺表现。

## 3. ID, OD and conditions belong together / 内外径、材质与工况一起核对

- **ID — inner diameter / 内径:** identify the flow-path dimension and its unit.
- **OD — outer diameter / 外径:** identify the outside tubing dimension and its unit.
- **Material / 材质:** provide the material family and an available specification reference; a material-family name alone may be insufficient.
- **Condition / 工况:** state temperature, pressure, sterilization method and history, fluid characteristics, and dry or liquid-filled operation as relevant.
- **Source and uncertainty / 依据与未知项:** distinguish nominal labels, confirmed specifications and measured values. Leave unverified fields marked **to confirm / 待确认**.

Keep units explicit and do not interchange ID and OD. When dimensions are unavailable, request a specification review instead of reconstructing them from a product code.

请明确单位，不混用内径和外径。尺寸资料不全时，应先核对规格，避免根据货号反推尺寸。

## 4. TFF pump flow is not processing throughput / TFF 泵流量不等于处理量

A recirculation-flow figure describes liquid circulating through the loop. The same liquid may pass through the loop repeatedly. It does not, by itself, state how much starting material can be concentrated or how much permeate can be collected in a given time.

循环流量描述液体在回路中的循环情况，同一部分液体可能多次经过回路。单凭循环流量，无法直接确定一定时间内能浓缩多少起始物料，或能收集多少透过液。

Keep these quantities separate in an inquiry:

| Quantity / 量 | Describe it clearly / 说明方式 |
| --- | --- |
| Recirculation or feed flow / 循环或进料流量 | Identify the stream, unit and expected operating range / 明确是哪一路液流、单位和预期工作范围 |
| Starting and final volumes / 起始与终体积 | State the batch size and concentration endpoint / 说明批次体积与浓缩终点 |
| Permeate collection / 透过液收集 | State the intended collection or buffer-exchange objective / 说明收集或换液目标 |
| Membrane and available area / 膜与可用面积 | Identify the proposed membrane type and the area that remains to be selected or confirmed / 说明拟用膜型及待选或待核对的面积 |
| TMP and measurements / 跨膜压与测量 | State the intended TMP and how pressure will be measured; mark it to confirm if unknown / 说明目标 TMP 及压力测量方式，未知则待确认 |
| Time and process behavior / 时间与工艺表现 | Define the desired process time and what evidence is available for the actual feed / 说明期望处理时间，以及针对实际料液已有何种依据 |

Processing time needs a review of the actual feed, membrane area, permeate behavior and operating conditions. A pump-flow specification alone is insufficient for a throughput commitment. Use a separate transfer-flow requirement when selecting a pump solely for liquid transfer.

处理时间需要结合实际料液、膜面积、透过情况及运行条件核对。仅有泵流量参数不足以承诺处理量；如果只是选输送泵，应另行说明输送流量需求。

## 5. Scope, documentation and the next step / 范围、文件与下一步

Use the [checklist](inquiry-checklist.md) to send an anonymized functional summary. Include quantity, destination country/region, required documentation and planning dates where relevant. Supply configuration, compatibility, destination requirements, price, availability and delivery terms must be confirmed individually.

请按[询价清单](inquiry-checklist.md)提供脱敏的功能需求，并在适用时注明数量、目的地国家或地区、所需文件及计划时间。供货配置、适配性、目的地要求、价格、可供情况与交付条款须逐项确认。

**An inquiry does not place an order or make a payment.** This guide provides a starting point for selection discussions. It does not establish manufacturer status, authorized-distributor status, certification, destination registration or process validation.

**提交询价尚未下单或付款。** 本指南用于开始选型沟通，不作为制造商身份、授权经销资质、认证、目的地注册或工艺验证的证明。

Share only information you are authorized to disclose. Start without customer records, confidential formulations, internal drawings, payment details or credentials. If technical documents are needed later, first agree on an appropriate review and handover method.

请仅分享有权披露的信息。初次询价不要提交客户记录、保密配方、内部图纸、付款资料或账号密码；后续如需技术文件，先确认适合的核阅与交接方式。
