## 2. Tubing connection and sealing are different operations / 接管与封管断开要分开

**Connection** joins applicable tubing segments to create a continuous path. A connection inquiry should identify both tubing segments and the intended connection conditions.

**接管**是连接适配的管路段，形成连续通路。询价时应分别说明两端管路及连接条件。

**Sealing and disconnection** closes applicable tubing before separation. State whether a sealed end, a defined separation step or both are needed. Confirm how separation is performed for the proposed configuration.

**封管与断开**是在分离前形成封管端。请说明需要封闭管端、分离动作还是两者兼有，并核对拟选配置的具体分离方式。

For either operation, review tubing formulation/grade, ID, OD, sterilization history, dry or liquid-filled state and process conditions. A diameter range alone does not confirm compatibility or the performance of the final process.

两类操作均需核对管材配方或等级、内外径、灭菌经历、空管或带液状态及实际工况。管径落入某个范围，仍不足以确认适配性或最终工艺表现。

## 3. ID, OD and conditions belong together / 内外径、材质与工况一起核对

- **ID — inner diameter / 内径:** identify the flow-path dimension and its unit.
- **OD — outer diameter / 外径:** identify the outside tubing dimension and its unit.
- **Material / 材质:** provide the material family and an available specification reference; a material-family name alone may be insufficient.
- **Condition / 工况:** state temperature, pressure, sterilization method and history, fluid characteristics, and dry or liquid-filled operation as relevant.
- **Source and uncertainty / 依据与未知项:** distinguish nominal labels, confirmed specifications and measured values. Leave unverified fields marked **to confirm / 待确认**.

Keep units explicit and do not interchange ID and OD. When dimensions are unavailable, request a specification review instead of reconstructing them from a product code.

请明确单位，不混用内径和外径。尺寸资料不全时，应先核对规格，避免根据货号反推尺寸。

## 4. TFF pump flow is not processing throughput / TFF 泵流量不等于处理量

A recirculation-flow figure describes liquid circulating through the loop. The same liquid may pass through the loop repeatedly. It does not, by itself, state how much starting material can be concentrated or how much permeate can be collected in a given time.

循环流量描述液体在回路中的循环情况，同一部分液体可能多次经过回路。单凭循环流量，无法直接确定一定时间内能浓缩多少起始物料，或能收集多少透过液。

Keep these quantities separate in an inquiry:

| Quantity / 量 | Describe it clearly / 说明方式 |
| --- | --- |
| Recirculation or feed flow / 循环或进料流量 | Identify the stream, unit and expected operating range / 明确是哪一路液流、单位和预期工作范围 |
| Starting and final volumes / 起始与终体积 | State the batch size and concentration endpoint / 说明批次体积与浓缩终点 |
| Permeate collection / 透过液收集 | State the intended collection or buffer-exchange objective / 说明收集或换液目标 |
| Membrane and available area / 膜与可用面积 | Identify the proposed membrane type and the area that remains to be selected or confirmed / 说明拟用膜型及待选或待核对的面积 |
| TMP and measurements / 跨膜压与测量 | State the intended TMP and how pressure will be measured; mark it to confirm if unknown / 说明目标 TMP 及压力测量方式，未知则待确认 |
| Time and process behavior / 时间与工艺表现 | Define the desired process time and what evidence is available for the actual feed / 说明期望处理时间，以及针对实际料液已有何种依据 |

Processing time needs a review of the actual feed, membrane area, permeate behavior and operating conditions. A pump-flow specification alone is insufficient for a throughput commitment. Use a separate transfer-flow requirement when selecting a pump solely for liquid transfer.

处理时间需要结合实际料液、膜面积、透过情况及运行条件核对。仅有泵流量参数不足以承诺处理量；如果只是选输送泵，应另行说明输送流量需求。
